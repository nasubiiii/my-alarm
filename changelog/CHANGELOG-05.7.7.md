# Update 05.7.7 — オイルタイマー終了時の完全停止

- 終了後はWebGL描画を固定し、液滴の落下・着水時の波紋をすべて停止します。
- 最後の液滴が途中に残らないよう、終了状態では下部の蓄積液体を最終状態として描画します。
- 計時終了直後、残っていたrequestAnimationFrameの更新を抑止します。
- 一時停止時も移動と揺れが止まり、再開時は停止位置から続きます。
- リセット後は初期表示へ戻します。
- オイルのシェーダーとレンダーループ以外の計時処理、他タイマーの処理は変更していません。
- JavaScript構文はチェック済み。ブラウザ・Android実機のWebGL描画は未検証です。
